# Caregiver Research Tracker Template

Use one row per adult participant. Do not place child identifiers or contact details in this tracker.

| Field | Entry |
|---|---|
| Participant code | P-001 |
| Consent confirmed | Yes / No |
| Interview date | YYYY-MM-DD |
| Interviewer | Initials or role |
| Broad caregiver context | Optional, non-identifying |
| Current bedtime routine | Notes |
| Main pain point | Notes |
| Current workaround | Notes |
| Last concrete example | Notes |
| Concept A reaction | Notes |
| Concept B reaction | Notes |
| Screen-off listening need | Notes |
| Trust/privacy concerns | Notes |
| Past spending behaviour | Notes |
| Price response | Notes; separate stated intent from past behaviour |
| Reasons not to use | Notes |
| Strongest evidence | Quote or observed behaviour, anonymised |
| Contradictory evidence | Notes |
| Confidence | Low / Medium / High with rationale |
| Follow-up consent | Yes / No |
| Researcher interpretation | Separate from participant statements |

## Synthesis after each interview

- What did we learn that we did not expect?
- Which assumption was supported?
- Which assumption was contradicted?
- What remains ambiguous?
- What product decision, if any, could this change?
- What additional participant profile would help challenge this finding?

## Aggregate review

After the planned sample:
- Count recurring themes without implying statistical significance.
- Preserve negative cases and dissent.
- Compare actual past behaviour with hypothetical interest.
- Identify differences across broad contexts.
- Update the product hypothesis and decision log.
- Record whether evidence supports, narrows, changes, or rejects the current proposition.
